AppInstall 1.0 build 45

BASE
- Criada diretamente da build 44 estável.

NOVO - VERIFICAR NOVAMENTE
- Novo botão pequeno "↻ Verificar" ao lado do WinGet.
- Ao clicar, consulta novamente as versões de TODOS os programas da lista.
- O resultado resumido é enviado para o log:
  Verificação concluída • N atualização(ões) • N não instalado(s) • N atualizado(s).
- O botão fica desabilitado durante instalações, atualizações e outras verificações.

NOVO - ORDENAÇÃO AUTOMÁTICA DA LISTA
Após cada verificação, a lista é organizada automaticamente nesta prioridade:

1. Não instalado
2. Atualização disponível
3. Atualizado

Dentro de cada grupo, os programas ficam em ordem alfabética.

A ordenação também é atualizada após uma instalação/atualização terminar.

MANTIDO
- Ao adicionar programa pela Pesquisa, somente os novos itens são verificados.
- Contador moderno de programas.
- Instalar somente programas não instalados e marcados.
- Atualizar somente atualizações marcadas.
- Download e instalação em uma única linha do log.
- Detecção Google.Chrome / Google.Chrome.EXE.
- WinGet automático.
- Java 8 compatível.

Compile com PUBLICAR.cmd.
